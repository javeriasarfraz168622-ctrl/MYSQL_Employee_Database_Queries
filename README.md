# MySQL Employee Database Queries

## About This Project
This repository contains my MySQL practice assignment based on the EMP employee table and PUCIT student table.

The purpose of this assignment is to practice SQL queries and understand different MySQL functions.

## Topics Covered

- SELECT Statements
- WHERE Clause
- LIKE Operator
- ESCAPE Clause
- CONCAT() Function
- REPLACE() Function
- LENGTH() Function
- SUBSTRING() Function
- SUBSTRING_INDEX() Function
- TRIM() Function
- REPEAT() Function
- YEAR() Function
- IFNULL() Function
- ORDER BY Clause
- Aggregate and String Operations

## Assignment Tasks

1. Display employee names, jobs, salaries, and hiring dates.
2. Replace characters in employee names and job titles.
3. Display employee details using CONCAT().
4. Remove leading characters from job titles.
5. Search employee names using LIKE and ESCAPE.
6. Count occurrences of a specific character in employee names.
7. Display salary-based stars using REPEAT().
8. Filter employees based on department and commission.
9. Extract and modify employee names.
10. Retrieve first names from student names.
11. Extract characters from specific positions in employee names.
